# Paper Outline
FIGA operates by contrasting low-quality initial LLM responses (ˆY) with minimally revised, high-quality responses (˜Y) generated by a powerful LLM (e.g., ChatGPT), based on ground-truth data (Y). This process identifies specific 'good actions' (newly added tokens) and 'bad actions' (deleted or substituted tokens). The SPA dataset is constructed by: 1) generating initial responses from a rollout model (e.g., Alpaca-7b), 2) filtering instances using a reward model (e.g., OpenAssistant DeBERTa) to select queries where the initial model performs poorly but a high-quality revision exists (RˆY < η1, RY > η2, RY − RˆY > η3), and 3) having ChatGPT revise ˆY to ˜Y with minimal changes, guided by identified reasons for poor quality, to reduce distribution shifts. For fine-tuning, FIGA employs a new loss function that assigns token-level weights based on Levenshtein distance between ˆY and ˜Y. Tokens newly added or substituted in ˜Y are rewarded (weight α), while tokens deleted or substituted in ˆY are penalized (weight β), and unchanged tokens are overlooked (weight γ=0). This loss function encourages desired actions and discourages undesired ones, acting as a simplified, efficient version of reinforcement learning.
