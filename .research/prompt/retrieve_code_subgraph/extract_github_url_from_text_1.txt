# Paper Outline
The core methodology is an LLM-driven objective discovery pipeline. It iteratively prompts a Large Language Model (specifically GPT-4) to propose and implement new preference optimization loss functions as code. The process starts with an initial context of established loss functions and their performance. For each proposed objective, unit tests ensure validity, and the function is then evaluated by fine-tuning an LLM and collecting a performance metric (e.g., MT-Bench scores). This performance feedback is fed back to the LLM as in-context examples, allowing it to iteratively refine its proposals by exploring variations of successful formulas or entirely new formulations. This process is conceptualized as meta-optimization, where the LLM directly generates code-level objective functions, eliminating the need for a predefined search space.
